# assets

Every graphic on the profile page is generated here, so the page doesn't depend
on a third-party card service being up.

| File | Generated by | Refreshed |
|---|---|---|
| `banner.svg` | `make_banner.py` | by hand, when the text changes |
| `divider.svg` | `make_banner.py` | by hand |
| `stats.svg` | `make_stats.py` | daily, by `.github/workflows/stats.yml` |

## How it works

`pixelfont.py` holds the shared parts:

- the 15 TMS9918A palette entries, copied from
  [`vrEmuTms9918Util.c`](https://github.com/visrealm/vrEmuTms9918/blob/main/src/vrEmuTms9918Util.c)
- a 5x7 pixel font on an 8x8 cell grid, the way a VDP pattern table works
- 8x8 sprite patterns for the drifting sprites in the banner
- `panel()`, the CRT chrome: bezel, cell grid, vignette, scanlines and roll bar

Glyphs are run-length encoded per row and merged vertically, so a letter costs a
handful of `<rect>`s rather than one per pixel. Animation is plain CSS inside the
SVG, which survives GitHub's image proxy.

## Regenerating

```sh
cd assets
python make_banner.py
python make_stats.py     # set GITHUB_TOKEN to avoid the 60/hour anonymous limit
```

`make_stats.py` walks every non-fork repo for its language breakdown and caches
the results in `.cache/` against each repo's `pushed_at`, so repeated local runs
cost almost no API calls. If any repo's language data cannot be fetched it exits
without writing, rather than publishing percentages computed from partial data.

No dependencies beyond the Python standard library.
